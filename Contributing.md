# Contributing

Thanks for helping improve DailyPages!

1. Open an issue describing the bug or feature.
2. Create a branch: `git checkout -b feature/short-description`.
3. Keep changes focused and add/update tests when practical.
4. Run backend tests with `cd backend && pytest`.
5. Run the frontend with `cd frontend && npm run dev`.
6. Open a pull request describing the change.

Please do not commit journal entries, secrets, local databases, or `.env` files.
